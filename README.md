# Capy Tech Landing Page (Light Mode)

This is the official **Light Mode** landing page for **Capy Tech Performance Digital**, built with high-intent lead acquisition, Local SEO positioning, and ultra-fast loading speed in mind.

## 🚀 Quick Start

To preview the landing page locally:

1. Run the local preview server:
   ```bash
   npm start
   ```
2. Open your browser and navigate to:
   ```
   http://localhost:8000
   ```

## 🛠️ Tech Stack & Architecture

- **HTML5 & Vanilla JS:** Clean semantic elements, lightweight execution.
- **Tailwind CSS (Play CDN):** Responsive and beautiful design without complex build/bundling chains.
- **Google Fonts:**
  - *Geist* & *Space Grotesk* for sleek, modern, and readable typography.
- **Google Material Symbols:** Iconography for clean service-module cues.
